# Инструкция по начальной настройке модуля "Управление IT-фирмой"

## 1. Настройка интеграции с Телеграм

### Шаг 1: Создание бота через @BotFather

Бот — это посредник, который будет доставлять сообщения из вашей IT-системы в чат.

1. Найдите в Telegram официального бота **@BotFather** (он всегда имеет значок галочки ✅ «Официальный»).

2. Начните с ним чат и отправьте команду `/start`. Он выведет список доступных команд.

3. Отправьте команду `/newbot`.

4. BotFather попросит придумать имя бота (например, `My Company Notifications`). Это имя, которое будут видеть пользователи в чате.

5. Затем придумайте техническое имя бота. Оно должно быть уникальным и обязательно заканчиваться на `bot` (например, `my_company_it_bot` или `mycompanynotifbot`).

6. Если имя свободно, BotFather пришлет вам сообщение с токеном доступа. Токен выглядит так: `110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`.

> ⚠️ **Важно!** Этот токен — пароль вашего бота. Никому его не показывайте и не публикуйте в открытом доступе. Тот, у кого есть токен, может управлять вашим ботом.

### Шаг 2: Создание группы и добавление бота

Вам нужен общий чат, куда бот будет присылать уведомления (например, «IT-Отдел: Уведомления»).

1. Создайте новую группу в Telegram или выберите уже существующую.

2. **Добавьте в группу созданного вами бота.** Для этого:

	- Нажмите «Добавить участников» в интерфейсе группы.

	- Введите техническое имя вашего бота (то, которое заканчивалось на bot).

	- Выберите его из списка и добавьте.

3. **Обязательно выдайте боту права администратора** (это часто требуется для отправки сообщений). Для этого:

	- Перейдите в «Управление группой» → «Администраторы».

	- Найдите добавленного бота и назначьте его администратором.

	- **Можно снять все галочки с прав, кроме «Отправка сообщений»** — этого будет достаточно.

### Шаг 3: Получение ID группы (Group Chat ID)

ID группы — это уникальный числовой идентификатор, который нужен системе, чтобы понять, куда отправлять сообщения.

#### Способ 1: C помощью бота @getmyid_bot

Это самый простой и надежный способ.

1. Найдите бота **@getmyid_bot** в Telegram.

2. **Добавьте этого бота в вашу целевую группу** (ту, куда планируете получать уведомления).

3. В группе напишите любую команду, например, `/start` или просто любое сообщение.

4. Бот @getmyid_bot моментально ответит вам, указав всю необходимую информацию.

5. **Скопируйте число, указанное в поле** `Chat ID:`. Оно будет отрицательным (например, `-1001426551252`). Отрицательное значение означает, что это ID группы (супергруппы), а не личного чата.

#### Способ 2: Через веб-браузер

1. Откройте Telegram Web в браузере: https://web.telegram.org и перейдите в нужную группу.

2. В адресной строке браузера вы увидите URL вида: `https://web.telegram.org/k/#-1234567899876`

3. **ID группы — это число после** `#` (в данном случае `-1234567899876`). Скопируйте его вместе с минусом.

> 💡 **Примечание:** Убедитесь, что ID является достаточно длинным числом (обычно 9-12 цифр) и **обязательно начинается со знака минус.** Если минуса нет, значит, вы скопировали ID личного чата, а не группы.

### Шаг 4: Настройка в системе "Управление IT-фирмой"

1. Откройте в вашей системе обработку «Подключение Телеграм бота».

2. В поле «Токен телеграм» вставьте токен, полученный от **@BotFather**.

3. В поле «Идентификатор группы» вставьте в нее скопированный **ID группы** (например, `-1001426551252`).

4. Сохраните изменения и запустите обработку / завершите настройку.

### Шаг 5: Проверка работы

Для проверки отправьте тестовое уведомление из системы (в обработке настройки обычно есть кнопка «Отправить тестовое сообщение»). Если все настроено верно, сообщение моментально появится в вашей Telegram-группе.

**Готово!** Теперь ваша система будет автоматически отправлять уведомления в выбранный Telegram-чат.

## 2. Настройка номенклатуры

### Шаг 1: Создайте в справочнике "Номенклатура" элементы

1. Для абонентской платы (например, "Абонентское обслуживание")

2. Для работ специалиста (например, "Работы специалиста")

### Шаг 2: Укажите созданные элементы в обработку «Заполнение констант номенклатуры»

1. В поле "Номенклатура абонентская плата" выбрать соответствующую номенклатуру.

2. В поле "Номенклатура работы специалиста" выбрать соответствующую номенклатуру.

3. Сохраните изменения и запустите обработку / завершите настройку
