# Руководство по автоматизированному тестированию с Vanessa Automation

Vanessa Automation (VA) — это фреймворк для автоматизации тестирования прикладных решений на платформе «1С:Предприятие». Он позволяет описывать тесты на языке Gherkin в виде сценариев (feature-файлов), которые легко читать и понимать даже не техническим специалистам.

Gherkin — это язык поведения системы, использующий структуру «Given-When-Then» (Дано-Когда-То). 

## Предварительные требования

Vanessa Automation: Скачайте последнюю версию обработки vanessa-automation.epf с официального репозитория на GitHub:
https://github.com/Pr-Mex/vanessa-automation

Тестовые сценарии: Скачайте файлы с расширением .feature и сохраните их на локальном диске.

## Настройка Менеджера тестирования

Менеджер тестирования — это отдельная база 1С, из которой запускаются все тесты.

1. Создайте пустую информационную базу (например, «Vanessa Automation Manager»).

2. Настройте параметры запуска этой базы:

	- Откройте ярлык запуска 1С в конфигураторе или в режиме предприятия.

	- Укажите следующие дополнительные параметры: `/TESTMANAGER /N Администратор /P "" /Execute "ПолныйПуть\vanessa-automation.epf"`

	`/TESTMANAGER` — запускает базу в режиме менеджера тестирования.
	`/N ""` - имя пользователя запускаемой конфигурации;
	`/P` - пароль пользователя указанного в ключе /N;
	`/Execute` — укажите полный путь к файлу vanessa-automation.epf.

	Пример:

	`/TESTMANAGER /N Администратор /P "" /Execute "C:\Vanessa\vanessa-automation.epf"`

3. Запустите базу. Должен автоматически открыться интерфейс Vanessa Automation.

## Добавление клиентов тестирования
Клиент тестирования — это ссылка на тестируемую базу, которая будет управляться из менеджера.

1. В интерфейсе VA перейдите на вкладку «Клиенты тестирования».

2. Нажмите кнопку «Добавить».

3. Заполните параметры для каждого клиента (пользователя):

	- Наименование: Произвольное имя для идентификации (например, "Менеджер", "Бухгалтер").

	- Строка подключения: Параметры запуска тестируемой базы для конкретного пользователя.

		- Для пользователя "Менеджер": /N "Менеджер" /P "ПарольМенеджера"

		- Для пользователя "Специалист": /N "Специалист" /P "ПарольСпециалиста"

		- Для пользователя "Бухгалтер ИТ": /N "Бухгалтер ИТ" /P "ПарольБухгалтера"

	- ИБ для тестирования: Укажите путь к тестируемой базе данных.

4. Добавьте трёх клиентов с разными правами доступа, как указано выше.

## Запуск тестовых сценариев

1. Перейдите на вкладку «Запуск сценариев».

2. Скачать файлы можно по [ссылку](/feature-files).

3. На панели инструментов нажмите кнопку «Открыть» (или Ctrl+O) и выберите первый файл сценария (например, СозданиеДокументовОбслуживаниеОтИмениМенеджер.feature). Текст сценария загрузится в левую часть окна.

4. В выпадающем списке «Клиент» выберите соответствующего пользователя (например, для первого сценария — «Менеджер»).

5. Нажмите кнопку «Запустить» для начала выполнения теста.

## Анализ результатов

- Успешное выполнение: Все шаги сценария будут подсвечены зелёным цветом. В нижней части окна появится статус: "Выполнение сценариев закончено. Ошибок не было".

- Ошибка при выполнении: Шаги до ошибки будут зелёными, шаг с ошибкой — красным. В логах и на вкладке «Отчёт» появится подробное описание ошибки.
